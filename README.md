## Starting the App

To get started with the application, follow these steps:

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Run the Development Server**:
   ```bash
   npm run dev
   ```
   This will start the development server, and the application will be accessible locally.
3. **Start JSON Server for Content Data:** To serve the content from db.json, run the following command:
   ```bash
    json-server --watch db.json --port 5000
   ```
   This will start a local server for db.json on port 5000.
